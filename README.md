# Sequential_Projects

A collection of sequential digital design projects implemented in Verilog HDL. This repository demonstrates RTL design, finite state machine (FSM) implementation, and timing-based sequential circuits for simulation and FPGA development.

## 📁 Projects

- ⏰ Digital Clock
- ⏱️ Stopwatch
- 🚦 Traffic Light Controller
- 🛗 Elevator Controller
- 🔍 Sequence Detector
- ⚡ Pulse Generator

## 🛠️ Tools

- Verilog HDL
- ModelSim / QuestaSim

## ✨ Features

- Synthesizable RTL code
- Modular and well-documented design
- Simulation-ready implementation
- FPGA-friendly architecture
- FSM-based control logic

## 📚 Learning Objectives

- Sequential circuit design
- Finite State Machine (FSM)
- Counters and Timers
- Clock-driven digital systems
- RTL coding in Verilog HDL
